# Issue tracker: GitHub

Use GitHub Issues in Seth-arc/debrio. Prefer the connected GitHub
tools; authenticated gh is an alternative when installed.
Verify the repository before writes. Tracker selection alone does
not authorize ticket or label creation.

The promptbook card remains the delivery brief. Link authorized
issues to its task ID, task record and any docs/tasks/<task-id>/spec.md;
do not duplicate the specification. Search before creating a ticket.
P0-01 delivery uses its PR and existing task record without a new issue.

Read the originating issue and its comments when supplied. Respect
native dependencies, or explicit Blocked by references when unavailable.
Follow WORKFLOW.md's dependency gates; a closed issue alone is not proof.

PRs as a request surface: no.
No triage labels are configured because triage is not installed.
